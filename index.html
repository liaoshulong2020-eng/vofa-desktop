如何选择 COM 串口设备？

当数据源选择为“Web Serial API (真实硬件串口)”并点击“选择 COM 口并连接”时，Chrome 或 Edge 浏览器顶部会自动弹出原生 COM 端口选择卡片。直接在弹窗中选中您的 USB 转串口设备（如 COM3, COM5, CH340, CP2102）并点击“连接”即可。
